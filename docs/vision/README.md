# Vision

Define la razon de existir del proyecto: que problema resuelve, quien lo
usara, cuales son los objetivos y cual es el alcance inicial.

---

## Documentos

| Archivo | Contenido |
| ------- | --------- |
| `vision.md` | Problema que resuelve, solucion propuesta, usuarios y principios. |
| `objectives.md` | Objetivos especificos del MVP y del futuro, con metricas de exito. |
| `scope.md` | Alcance y limites de la version 1: que entra, que no, y supuestos. |

## Orden de lectura

1. `vision.md` — el por que del proyecto.
2. `objectives.md` — que queremos lograr y como lo medimos.
3. `scope.md` — las fronteras del MVP.
