# UI

Define la experiencia de usuario: pantallas, navegacion, componentes y
sistema visual.

---

## Documentos

| Archivo | Contenido |
| ------- | --------- |
| `00-ui-overview.md` | Principios de diseno, navegacion y temas. |
| `01-pages.md` | Definicion de cada pantalla con elementos y estados. |
| `02-components.md` | Componentes reutilizables: botones, formularios, tarjetas, feedback. |
| `03-design-system.md` | Paleta de colores (claro/oscuro), tipografia, espaciado, accesibilidad. |

## Orden de lectura

1. `00-ui-overview.md` — vision general del diseno.
2. `03-design-system.md` — sistema visual (colores, tipografia).
3. `01-pages.md` — pantallas concretas.
4. `02-components.md` — piezas reutilizables.

## Consejos

- Documenta los estados vacios y de error: son los que mas se olvidan.
- Si cambias un componente, actualiza su documentacion en el mismo cambio.
