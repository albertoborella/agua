# .ai (contexto para agentes de IA)

Contexto que los agentes de IA leen antes de trabajar: contexto del
proyecto, guia de prompts, workflow, estandares y definition of done.

---

## Documentos

| Archivo | Contenido |
| ------- | --------- |
| `project-context.md` | Contexto del proyecto para que un agente nuevo arranque rapido. |
| `prompt-guide.md` | Como escribir prompts efectivos para este proyecto. |
| `workflow.md` | Flujo de trabajo: como se hacen los cambios, reviews y commits. |
| `glossary.md` | Glosario del proyecto (ademas del glosario SDD global). |
| `definition-of-done.md` | Criterios de terminado para tareas y cambios. |
| `coding-standards.md` | Estandares de codigo: Python (PEP 8), Dart (effective Dart), SQL. |

## Orden de lectura

1. `project-context.md` — que es el proyecto y su stack.
2. `coding-standards.md` — como escribir codigo.
3. `workflow.md` — como hacer commits y PRs.
4. `definition-of-done.md` — cuando una tarea esta lista.

## Consejos

- Este contexto es lo primero que lee un agente de IA antes de trabajar.
- Mantenelo corto y accionable: los agentes no leen manuales largos.
